# Segurança

## Antes de publicar

1. Troque a senha de demonstração `admin`.
2. Configure somente os hostnames autorizados em `PORTAL_HOSTS`.
3. Use HTTPS e mantenha o cookie de sessão seguro.
4. Não envie a pasta `data/`, arquivos `.env`, uploads, logs ou backups ao GitHub.
5. Revise os membros, documentos, lançamentos financeiros e imagens antes de cada exportação pública.

## Relato de vulnerabilidades

Não publique vulnerabilidades com dados sensíveis em uma issue. Entre em contato de forma privada com o mantenedor do fork em que o problema foi encontrado.
